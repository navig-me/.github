# NAVIG

Practical tools for daily life in Singapore and Malaysia, plus a few for developers and teachers. Built by [Mihir Khandekar](https://www.linkedin.com/in/mihir-khandekar/) because we needed them.

## NAVIG.me

[navig.me](https://navig.me/) is a set of live maps and trackers. No sign-up needed.

| Tool | What it does |
|---|---|
| [Bus arrivals](https://navig.me/bus) | Live Singapore bus arrivals, crowding and bus locations |
| [Live bus map](https://navig.me/buses-live-map) | Every active bus in Singapore on one map |
| [MRT](https://navig.me/mrt) | Crowd levels, service alerts and station trends |
| [NAVIG Sea](https://navig.me/sea) | Live vessel map, arrivals, departures and weather for Singapore waters, with an AR spotter at [/sea/spot](https://navig.me/sea/spot) |
| [Recycling](https://navig.me/recycling) | Nearest BCRS return machines for bottles and cans, with working or full status |
| [Carparks](https://navig.me/carpark) | Real-time HDB, URA and LTA carpark lots |
| [Traffic](https://navig.me/traffic) | Incidents, speed bands, expressway travel times |
| [Bicycle parking](https://navig.me/bike) and [EV charging](https://navig.me/ev-charging) | Nearest racks and chargers |
| [Weather](https://navig.me/weather) | Rain forecasts, air quality and flood alerts |
| [Malaysia transit](https://navig.me/my/prasarana/rapid-bus-kl) | KTMB, RapidKL and MyBas schedules and routes |
| [Telegram bot](https://navig.me/telegram-bot) | Bus arrival alerts in Telegram |

## More products

- **[ClassOps](https://classops.app/)**: class management for independent teachers, tutors and small studios. Leads, trials, scheduling, attendance, reminders and make-up classes.
- **[PingWing](https://pingw.ing)**: flight tracking by flight number or boarding pass, with alerts for gate changes, delays and baggage.
- **[EatHealthy.fyi](https://eathealthy.fyi/)**: restaurants matching your diet (vegetarian, vegan, halal, gluten-free) across 15+ cities.
- **[TinyPrune](https://tinyprune.com/)**: local-first macOS file cleanup. Give downloads and screenshots an expiry date, preview matches, and expired items go to Trash. Open source: [navig-me/tinyprune](https://github.com/navig-me/tinyprune).

## Open source for developers

- **[Telert](https://github.com/navig-me/telert)**: get alerts when terminal commands or Python code finish. Telegram, Slack, Teams, Discord, desktop and HTTP.
  ```bash
  pip install telert
  sleep 60 | telert "Job done!"
  ```
- **[WhoWhyWhen](https://github.com/navig-me/whowhywhen)**: API analytics, bot detection and performance monitoring.
- **[local-marketing](https://github.com/navig-me/local-marketing)**: local-only outreach skill for coding agents, with a SQLite CRM and file-approved sends.
